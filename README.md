# MEN Stack CRUD App Lab

## Step 1 – Project Setup

### What we did
- Created a GitHub repository
- Cloned it locally
- Created `server.js`
- Ran `npm init`
- Set entry point to `server.js`
- Created `package.json`
- Made our first commit

### Why we did it
We prepared a clean Node project that is connected to GitHub and ready to become a full MEN stack app.

### Key Concepts Learned

**Remote**
The online version of our project (GitHub).

**Origin**
The default nickname for the main remote repository.

**Clone**
Download a GitHub repo and automatically connect it to our local machine.

**package.json**
The control center of a Node project. It tracks dependencies and project settings.

### Engineering Principle
Always commit at clean checkpoints.
Small, clear commits = professional workflow.
